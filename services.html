What I can take on.

How a build runs

Three steps, always in this order.

  1. Step 1

    Scope

    We agree what done looks like and what is out of scope before any code gets written. Anything unclear, I ask about it then.

  2. Step 2

    Build

    Short iterations with something you can click at the end of each one, so you can steer it while it is still cheap to change.

  3. Step 3

    Ship

    Deployed, watched for a few days, and handed over with notes on how it runs and what to do when it breaks.
